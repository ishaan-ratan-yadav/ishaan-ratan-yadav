# Distribution, Growth, Monetization and Risk Playbook for Indie ChatGPT Apps (Apps SDK + Custom GPTs), as of October 2026

> **Method note for the report writer:** The egress proxy blocked full-page fetches for almost every relevant domain: developers.openai.com, community.openai.com, chatgptappsrank.com, waniwani.ai, alpic.ai and dev.to all returned "EGRESS_BLOCKED". So the findings below come from search-result snippets of the cited pages, not from reading each page in full. The parts that come from OpenAI's own submission-guidelines page (the digital-goods ban, the advertising ban, the 13–17 audience rule) showed up the same way across several separate searches, so I treat them as reliable. Numbers from vendor or "guide" blogs (getchatads, snaplama, gptstorerevenueprogram, wildnetedge, socialgrowthengineers) are lower quality and are labeled as such. Wherever a claim rests on a weak source, the bullet says so.

## 1. How discovery works (directory ranking, model invocation mid-conversation, featured placement, listing SEO)

### Takeaway
Discovery happens in two places. The first is the in-ChatGPT App Directory (chatgpt.com/apps), launched December 2025. Its search mostly indexes the app **name** and the **short description**, and editors feature apps that meet higher quality bars and keep users coming back. The second is model-driven invocation mid-conversation. ChatGPT picks an app when its tool metadata, its descriptions and past usage match the user's prompt. Clear, specific tool descriptions beat keyword stuffing, and keyword stuffing can get an app rejected.

### Cited Findings
- **Directory timeline:** OpenAI opened third-party app submissions on Dec 17, 2025. Apps that passed review began rolling out to users in early 2026. — [OpenAI: Developers can now submit apps to ChatGPT](https://openai.com/index/developers-can-now-submit-apps-to-chatgpt/); [VentureBeat](https://venturebeat.com/technology/openai-now-accepting-chatgpt-app-submissions-from-third-party-devs-launches); [OpenAIDevs on X](https://x.com/OpenAIDevs/status/2001419749016899868)
- **Where the directory lives:** It is a searchable in-app marketplace, reached from the ChatGPT tools menu or at chatgpt.com/apps. It is organized into categories such as Featured, Lifestyle and Productivity. One agency describes it as having "replaced the earlier GPT Store model" with SDK-powered integrations. — [Moburst](https://www.moburst.com/blog/chatgpt-app-directory-explained-what-brands-need-to-know/). (Caveat: I could not confirm whether custom GPTs and the GPT Store still sit alongside apps. That claim comes from an agency blog, not OpenAI.)
- **Directory size:** A community-maintained GitHub list counts **330 verified Apps SDK/MCP integrations** in the official directory. The snapshot date is not given in the snippet. — [awesome-chatgpt-apps (GitHub)](https://github.com/rdmgator12/awesome-chatgpt-apps)
- **Who dominates (mid-2026):** "Productivity and business apps still dominate the directory by count … partner companies with existing SaaS audiences ship first and cluster in the categories where those audiences already live." — [ChatGPTAppsRank, State of ChatGPT Apps 2026 (Mid-Year)](https://chatgptappsrank.com/state-of-chatgpt-apps-2026) (full report not fetchable, so its detailed stats are unknown)
- **Directory search signals:** "The app name carries the most indexation weight by a wide margin, and the short description is also indexed, but long-tail keyword queries don't surface results reliably yet. Individual keywords tend to perform better than multi-word phrases." — [WaniWani: ChatGPT App Directory Optimization](https://www.waniwani.ai/blog/chatgpt-app-directory-optimization) (vendor blog, based on its own observation)
- **Ranking and clarity:** "Ranking rewards how clearly the model understands your app's purpose, not how many keywords you packed into a listing." — [Noodle Seed: ChatGPT App Directory listing and discovery guide](https://noodleseed.com/blog/chatgpt-app-directory-optimization) (vendor blog)
- **Model-driven invocation (OpenAI docs wording, via snippet):** "Discovery in ChatGPT is model-driven: the assistant chooses your app when your tool metadata, descriptions, and past usage align with the user's prompt and memories. You can refine metadata and tool descriptions to improve discoverability." — [OpenAI Apps SDK docs: Research use cases](https://developers.openai.com/apps-sdk/plan/use-case)
- **Metadata fields that steer invocation and rendering:** Tools carry `_meta` keys such as `openai/toolInvocation/invoking`, `openai/toolInvocation/invoked`, `openai/widgetAccessible` and `openai/resultCanProduceWidget`. Resources carry `openai/widgetDescription`, a plain-language description written for the model. — [Medium: OpenAI Apps SDK Handbook](https://medium.com/@sumit-paul/building-custom-tools-and-widgets-for-chatgpt-the-openai-apps-sdk-handbook-fef47a7ba555); [Tollbit: How the OpenAI Apps SDK works](https://tollbit.com/blog/how-openai-apps-sdk-works/); [MCPJam apps-sdk-everything](https://github.com/MCPJam/apps-sdk-everything)
- **Evidence that richer metadata helps tool selection (general, not ChatGPT-specific):** An academic paper reports roughly a **27% improvement** in tool selection and invocation accuracy when tool metadata is enriched rather than minimal. — [arXiv 2509.11626: Automated Creation and Enrichment Framework for Improved Invocation of Enterprise APIs as Tools](https://arxiv.org/pdf/2509.11626)
- **Featured placement:** "Apps that meet higher design and functionality standards may be featured more prominently in the directory." "Apps that deliver consistent value and that users return to over time will earn more prominent placement." — [OpenAI: Developers can now submit apps](https://openai.com/index/developers-can-now-submit-apps-to-chatgpt/) (via snippet aggregation); [Moburst](https://www.moburst.com/blog/chatgpt-app-directory-explained-what-brands-need-to-know/)
- **Anti-manipulation:** "Stuffing your description with unnecessary terms or prompting triggers can get your app rejected outright." — [Moburst](https://www.moburst.com/blog/chatgpt-app-directory-explained-what-brands-need-to-know/); see also [Alpic: How to submit your app](https://alpic.ai/blog/how-to-submit-your-app-to-the-chatgpt-directory)
- **Listing assets required:** App icon, name, a verified website, short and long descriptions, screenshots, a configured MCP server, and detailed test cases showing the app works on both web and mobile. Only one version can be under review at a time. — [Moburst](https://www.moburst.com/blog/chatgpt-app-directory-explained-what-brands-need-to-know/)
- **Size of the audience:** OpenAI confirmed 900M+ weekly active users in February 2026. — [SEOProfy ChatGPT statistics (Sept 2026)](https://seoprofy.com/blog/chatgpt-statistics/). ChatGPT passed 1B monthly active app users in mid-2026, per Sensor Tower via Reuters. — [TechTimes](https://www.techtimes.com/articles/317841/20260605/chatgpt-reaches-1-billion-app-users-claudes-640-growth-splits-session-time.htm); [MLQ](https://mlq.ai/news/chatgpt-hits-1-billion-monthly-app-users-fastest-app-ever-to-reach-the-milestone/)

### Inferences
- Treat the **app name as the main search keyword**. A descriptive name with the core job in it, such as "Resume Roaster" rather than a coined brand, should be the biggest lever in the directory.
- For mid-conversation invocation, write each tool description as a precise "use this when the user wants X; do not use for Y" contract. Name the concrete user intents, add clear `widgetDescription` text, and keep tool scope narrow. The phrase "past usage" in OpenAI's wording suggests early engagement compounds. This is also how SaaS incumbents keep their edge.
- Featured placement appears to be editorial and to reward retention and design polish. Indies probably get more from a highly polished narrow utility than from broad coverage.
- Because SaaS incumbents dominate the directory by count, consumer and novelty niches (fun, lifestyle, creative) may be less crowded for indies. This is an inference; I have no numbers.

### Gaps
- No public data on directory traffic, install counts per app, or conversion from directory view to connect. ChatGPTAppsRank's detailed stats could not be fetched.
- No official OpenAI statement on directory ranking factors beyond "design/functionality standards" and "users return over time".
- No controlled public experiments showing which tool-description changes raised invocation rates inside ChatGPT specifically.
- I could not confirm whether the custom-GPT GPT Store still has its own leaderboard or ranking in October 2026.

## 2. Off-platform growth (short-form video, X build-in-public, Product Hunt, Reddit)

### Takeaway
I found **no well-documented case study with numbers for a ChatGPT Apps SDK app** growing through off-platform channels. The best evidence comes from standalone consumer AI apps that scaled with **networks of faceless short-form accounts**. Those numbers come from growth-marketing blogs and should be treated as directional. Product Hunt remains a useful one-day spike channel.

### Cited Findings
- **Gizmo AI (AI study app, not a ChatGPT app):** Ran **30+ faceless TikTok accounts** and reached **70M views and $59K MRR**. The main account had about 44.5M views. The format was close-up footage of colorful highlighted notes on a laptop, and one video reached 9.8M views, 702K likes and 141K saves. — [Social Growth Engineers](https://www.socialgrowthengineers.com/ai-study-app-running-30-faceless-accounts-to-70m-views-and-59k-mrr) (growth-marketing newsletter, secondary)
- **Emochi AI (character chat app):** A reported network of 25 faceless TikTok accounts posting daily, with about 200K downloads, **$70K MRR in 30 days** and 44M views (a 2025 analysis, so older). — [GPTProto](https://gptproto.com/news/emochi-ai) (weak source)
- **Cal AI (calorie app):** Claimed "$1.5M MRR in 34 days using only faceless TikTok explainer videos" built from screen recordings with voiceover. — via search aggregation of the [inreels / snapdance / rattibha threads](https://en.rattibha.com/thread/2039633201757335596). (**Treat as unverified.** The claim is extraordinary and repeated by marketing blogs, and I could not find a primary source.)
- **Watermarks and shares:** Claims that "subtle watermarking increases profile visits by 29%" and that faceless videos get "52% higher shares" with trending sounds. — [virvid.ai guide](https://virvid.ai/blog/viral-ai-tiktok-videos-complete-guide-2026) / [inreels](https://www.inreels.ai/blog/faceless-tiktok-ideas). These are vendor blogs with no methodology, so treat them as low reliability.
- **Product Hunt in 2026:** Still claims 2M+ monthly active users and 50+ launches per day, and is still described as a high-leverage launch channel. — [LaunchList: How to launch on Product Hunt 2026](https://getlaunchlist.com/blog/how-to-launch-on-product-hunt-2026) (vendor of launch tools)
- **Affiliate video example (custom-GPT adjacent):** One affiliate creator made a single video about CustomGPT.ai that brought in **$4,683 over four months** in commissions. — [CustomGPT.ai affiliates blog](https://customgpt.ai/customgpt-ai-affiliates-maximize-earnings-with-ai/) (self-published by the vendor)
- **Indie stack:** Indie hackers use Product Hunt alongside X, LinkedIn and SEO as their core go-to-market channels. — [Alignify: Indie Hackers 2026](https://alignify.co/insights/indie-hackers); [OnePC AI stack of solo founders 2026](https://onepc.org/stats/ai-stack-solo-founders-2026)

### Inferences
- The proven short-form pattern for AI consumer tools is **many faceless accounts, a repeated visual hook, and a screen recording of the "magic moment."** For a ChatGPT app that becomes: screen-record the prompt, show the widget rendering inline in ChatGPT, then show the result. The "inside ChatGPT" novelty is itself a hook.
- A ChatGPT app has a weak link-out for the viewer. They have to open ChatGPT, find the app and connect it. So the call to action should be the exact app name to search for, which ties back to the name-as-keyword point in Q1. A companion web landing page with a deep link may also help.
- Product Hunt and Reddit (r/ChatGPT, r/SideProject) are best as one-time spikes and for backlinks and credibility, not as sustained channels.

### Gaps
- No verified case study with install or user numbers for an indie Apps SDK app driven by TikTok, Reels, X or Product Hunt. Searching for this returned only general ChatGPT statistics.
- No data on whether deep links into a specific ChatGPT app exist or convert well. The OpenAI docs that would answer this could not be fetched.
- Could not retrieve specific X build-in-public threads or Reddit posts with numbers for ChatGPT apps.

## 3. Building shareability into the product (result cards, watermarks, referral loops, challenges)

### Takeaway
I found almost nothing ChatGPT-app-specific on built-in viral loops. Three constraints shape the design. Widgets render in an iframe inside ChatGPT. **Apps may not serve ads.** And apps may not upsell digital goods, which caps referral-for-credits schemes. Shareable output (images or cards with a subtle brand mark) seems to be the main option left.

### Cited Findings
- **How widgets work:** A widget is an HTML/JS/React bundle registered as an MCP resource. It renders inside ChatGPT's iframe and talks to ChatGPT both ways via JSON-RPC 2.0 over postMessage. — [Codex CLI blog: Building ChatGPT Apps](https://codex.danielvaughan.com/2026/05/14/building-chatgpt-apps-with-codex-cli-apps-sdk-mcp-server-widget-scaffolding/); [Vercel: Running Next.js inside ChatGPT](https://vercel.com/blog/running-next-js-inside-chatgpt-a-deep-dive-into-native-app-integration)
- **No ads:** "Apps must not serve advertisements and must not exist primarily as an advertising vehicle." — [OpenAI App submission guidelines](https://developers.openai.com/apps-sdk/app-submission-guidelines) (via snippet)
- **No digital-goods upsell:** Credits, tokens and subscriptions are not allowed "whether offered directly or indirectly (for example, through freemium upsells)." That rules out "refer a friend, get credits" loops sold inside the app. — [OpenAI App submission guidelines](https://developers.openai.com/apps-sdk/app-submission-guidelines)
- **Watermarks drive profile visits (low-quality source):** "Subtle watermarking increases profile visits by 29%." — [virvid.ai](https://virvid.ai/blog/viral-ai-tiktok-videos-complete-guide-2026)
- **AI disclosure:** TikTok Shop requires AI-generated content to be disclosed through on-screen text, a watermark, the description or the AI toggle. A brand watermark can double as that disclosure. — [RapidTok](https://rapidtok.com/blog/faceless-tiktok-shop-ai-video)

### Inferences
- Design the widget's output as a **downloadable or screenshot-friendly card**: a score, a roast, a personality result, or a before-and-after image. Use a 9:16 or 1:1 layout and put a small app-name mark on it, which also works as the search term. Screenshot sharing needs no permissions and breaks no policy.
- Challenge mechanics ("what did you get?") rely on deterministic, comparable outputs such as scores, tiers or archetypes. These fit the structured data a widget can render.
- Any referral program should reward non-monetary perks, or live entirely on the developer's own website, outside the app. This is an inference from the policy wording, so confirm it against the current guidelines before relying on it.

### Gaps
- No ChatGPT-app examples or data on share rates, referral loops or challenges.
- Unclear whether widgets can trigger native share sheets or file downloads in the ChatGPT iframe on mobile. This would need hands-on testing or the OpenAI UX docs, which were blocked.

## 4. Monetization paths: what works and real earnings

### Takeaway
**Direct monetization of digital products inside an Apps SDK app is prohibited as of the latest guidelines I could see.** Subscriptions, credits, tokens and digital content are banned even as indirect freemium upsells, and only physical-goods commerce via external checkout is allowed. Instant Checkout (Agentic Commerce) was **retired in March 2026**. The GPT Store revenue program never broadly launched, and the reported payouts are small. Realistic indie paths are: (a) the ChatGPT app as a free top-of-funnel for an external product or service; (b) lead generation; (c) physical-goods or marketplace commerce via link-out; (d) waiting for promised digital-goods support, rumored as "ChatPass."

### Cited Findings
- **Digital goods banned:** "Apps may conduct commerce only for physical goods. Selling digital products or services—including subscriptions, digital content, tokens, or credits—is not allowed, whether offered directly or indirectly (for example, through freemium upsells)." — [OpenAI App submission guidelines](https://developers.openai.com/apps-sdk/app-submission-guidelines) (wording repeated across several search snippets)
- **External checkout is the default path:** "External checkout redirects users to your merchant site for payment, and OpenAI currently recommends this approach for most developers." Developers "cannot currently submit an app with monetization for any digital products or services." — [OpenAI Apps SDK: Monetization](https://developers.openai.com/apps-sdk/build/monetization) (via snippet)
- **Link-out allowed for physical goods; digital goods "explored":** "In this early phase, developers can link out from their ChatGPT apps to their own websites or native apps to complete transactions for physical goods… OpenAI is exploring additional monetization options over time, including digital goods." — [OpenAI: Developers can now submit apps](https://openai.com/index/developers-can-now-submit-apps-to-chatgpt/)
- **Developer forum sentiment:** It has "been mentioned multiple times that OpenAI wants to allow usage/subscription monetization but not yet." — [OpenAI Dev Community: ChatGPT App Monetization](https://community.openai.com/t/chatgpt-app-monetization-apps-sdk/1372343); see also [Chatgpt app sdk with premium thread](https://community.openai.com/t/chatgpt-app-sdk-with-premium/1361287)
- **Rumored "ChatPass" / subscription sharing:** Reports describe an unreleased system that would meter part of a user's ChatGPT subscription allowance for third-party apps. **This is unconfirmed by OpenAI.** — [RuntimeWire](https://runtimewire.com/article/openai-is-building-subscription-sharing-for-ai-apps); [SaaSRise](https://www.saasrise.com/news/openai-turns-chatgpt-into-an-app-marketplace-extends-subscription-use-to-thirdparty-tools-7ab210a0-bd05-4c00-8f3f-e9deb457a3f9)
- **Conflicting claim:** One guide says ChatGPT apps "support monetization through Stripe and PayPal (in-app purchases)." — [Snaplama 2026 guide](https://www.snaplama.com/blog/how-to-create-chatgpt-apps-and-monetize-them-complete-2026-guide). **This is contradicted** by the OpenAI guidelines' ban on digital goods. Treat Snaplama as unreliable.
- **Instant Checkout history:** It launched Sept 29, 2025 with Etsy and was powered by Stripe and the Agentic Commerce Protocol (ACP). — [Stripe newsroom](https://stripe.com/newsroom/news/stripe-openai-instant-checkout). A 4% fee on Instant Checkout sales was set to start Jan 26, 2026. — [Ask-Luca](https://ask-luca.com/blogs/chatgpt-4-fee-starting-jan-2026-what-smart-merchants-do-now); [GetChatAds](https://www.getchatads.com/blog/chatgpt-checkout-affiliate-revenue/)
- **Instant Checkout retired in March 2026:** "OpenAI retired Instant Checkout in March 2026, about six months after it launched, and repositioned ChatGPT toward product discovery, with checkout moving back to merchants' own environments." Only about a dozen to 30 Shopify merchants ever went live. Walmart measured in-ChatGPT checkout converting **about 3× worse** than a click-through to Walmart.com, while ChatGPT drove **about 2× the new-customer rate** of search. ACP itself continues, with PayPal and Nexi joining as payment partners. — [Hypotenuse AI](https://www.hypotenuse.ai/blog/chatgpts-instant-checkout-the-next-phase-of-agentic-commerce); [Lengow](https://blog.lengow.com/chatgpt-wanted-to-become-the-worlds-biggest-shop/); [Digital Applied](https://www.digitalapplied.com/blog/ai-agentic-commerce-discover-in-ai-buy-on-site-2026); [Digital Commerce 360 (Feb 2026)](https://www.digitalcommerce360.com/2026/02/16/openai-expands-agentic-commerce-push/)
- **GPT Store builder revenue program:** It launched as a promise with the GPT Store in January 2024 (older). — [VentureBeat](https://venturebeat.com/ai/openai-launches-gpt-store-but-revenue-sharing-is-still-to-come). As of early 2026 it "never broadly launched and remains a limited, invite-only pilot restricted to a small group of US-based builders," with engagement-based payouts and an undisclosed formula. — [Digital Applied GPT Store guide 2026](https://www.digitalapplied.com/blog/gpt-store-custom-gpts-business-guide-2026); [Geeky Gadgets](https://www.geeky-gadgets.com/custom-gpt-revenue-program/)
- **Reported GPT Store payouts (low-quality sources):** "Most creators hit a soft ceiling of $100–500/month." "Most creators earn nothing … because they don't meet the 25 conversation minimum per week." Top creators earn "hundreds to a few thousand dollars." — [gptstorerevenueprogram.com](https://gptstorerevenueprogram.com/); [The GPT Shop blog](https://www.thegptshop.online/blog/openai-gpt-store-revenue-sharing). These are unofficial SEO sites with no named earners, so they are unverified.
- **Lead-gen anecdote (illustrative, unverified):** A logistics consultant's GPT reportedly generated about 50 qualified leads per month, with a direct payout of only about $200 but around $250K per year in consulting revenue. — [WildnetEdge](https://www.wildnetedge.com/blogs/chatgpt-app-monetization) (an agency blog, likely a hypothetical example)
- **Custom-GPT "$10K" case:** A press release claims $10K earned from custom GPTs through methods other than OpenAI revenue share. — [MarketersMedia press release, Dec 2025](https://markets.financialcontent.com/wral/article/marketersmedia-2025-12-5-10k-earned-with-custom-gpts-on-chatgpt-store-gpts-money-announces-case-study). This is a paid press release promoting a course, so it is low credibility.
- **B2B custom-GPT services:** Agencies charge $5K–20K upfront plus $1K–5K per month in maintenance to build internal enterprise GPTs. — [Digital Applied](https://www.digitalapplied.com/blog/gpt-store-custom-gpts-business-guide-2026) (agency claim)
- **Affiliate:** GPTs can recommend products with affiliate links and capture leads into a CRM. Personal finance, website builders, business tools and lead gen are cited as profitable GPT Store niches. — [WildnetEdge GPT Store monetization guide](https://www.wildnetedge.com/blogs/gpt-store-monetization-guide). Note the separate Apps SDK rule that apps must not "exist primarily as an advertising vehicle." — [OpenAI guidelines](https://developers.openai.com/apps-sdk/app-submission-guidelines)

### Inferences
- **Most viable indie model today:** a free, genuinely useful ChatGPT app that delivers standalone value (required by the guidelines) and acts as a **funnel** to the builder's own website, standalone app, newsletter or service, where monetization happens off-platform. The in-app upsell must not market digital goods, so the funnel has to rely on brand recall, an account the user links via OAuth, or useful features that naturally live on the website. Builders should read the "indirectly" clause carefully, because an explicit "upgrade to Pro" button inside the widget likely risks rejection.
- **OAuth account linking** lets an app recognize existing paying customers of an external SaaS. That is how incumbents like Adobe and Salesforce monetize: the app is a feature of a product sold elsewhere. Whether an indie can gate features behind an external subscription without breaking the "indirect upsell" rule is unclear and needs confirmation against the live guidelines.
- **Commerce apps** (physical goods, marketplaces, travel, local services) can earn affiliate or merchant revenue via link-out. The Walmart data suggests link-out converts better than in-chat checkout anyway.
- Do not plan around GPT Store revenue share. The evidence says it never paid meaningfully at scale.

### Gaps
- No verified, named earnings reports from indie Apps SDK builders.
- Unclear whether OpenAI had enabled digital-goods monetization or "ChatPass" by October 2026. The latest snippets still say it is not allowed, but the live docs could not be fetched to confirm.
- Exact wording on whether linking to an external subscription from inside an app counts as an "indirect" upsell was not retrievable.

## 5. Risks: platform/native-feature risk, review rejections, policy restrictions, retention, copycats, MCP hosting costs

### Takeaway
The main risks are: (1) **review friction**, with roughly 9–20+ day reviews, rejections that come with little explanation, and requirements that shift during review; (2) **policy limits**, meaning no digital-goods sales, no ads, apps that must suit 13–17-year-olds and must not target under-13s, and correct tool annotations; (3) **platform risk**, since OpenAI has repeatedly shipped features that wiped out wrapper startups and killed its own Instant Checkout within six months; (4) **thin moats and copycats**. Hosting cost is the smallest risk, because serverless MCP hosting on Vercel, Cloudflare Workers or Supabase scales to zero.

### Cited Findings
- **Review time and moving goalposts:** A forum thread reports reviews taking about **20 days just to get rejected** for requirements that changed during review. — [OpenAI Dev Community: Submissions take so long that requirements change](https://community.openai.com/t/submissions-take-so-long-that-requirements-change-which-leads-to-app-rejections/1392493). A separate team was rejected in **nine days**. — [DEV Community: rejected in nine days](https://dev.to/infoinlet1/we-submitted-our-mcp-server-to-the-chatgpt-apps-directory-it-was-rejected-in-nine-days-509o). Another developer reports a rejection with **no reason given**. — [OpenAI Dev Community: App rejected, no reason given](https://community.openai.com/t/app-rejected-no-reason-given/1378971)
- **Common rejection causes:**
  - Wrong tool annotations, for example a tool marked read-only that actually changes data.
  - Test credentials that do not give a fully working demo account with sample data. Apps that require sign-up or inaccessible 2FA are rejected.
  - Reviewer-run test prompts failing or producing unexpected results.

### Inferences
- Budget **2–4 weeks of review latency** per submission cycle and assume at least one rejection. Ship a reviewer-ready demo account and verbatim test prompts on day one.
- Avoid ideas that are a thin layer over something ChatGPT already does natively, such as generic writing, summarizing or image generation. Prefer apps that bring **proprietary data, real-time external data, or actions in an external system** ChatGPT cannot reach.
- Retention risk is structural. Users invoke apps per task, and "past usage" feeds invocation, so apps without a recurring job will fade. Pick a recurring use case such as daily, weekly or event-driven.
- The main hosting cost is any backend LLM or API inference the server itself runs, not MCP serving. Push generation onto ChatGPT's own model where possible.
- Copycat risk is high because Apps SDK apps are thin MCP servers. Speed, owning the descriptive name in directory search, and brand matter most.

### Gaps
- No public retention or DAU data for ChatGPT apps.
- I could not verify explicit category rules for companionship, health advice, financial advice or gambling in the Apps SDK guidelines, because the page was blocked. The report writer should flag these as "check the live guidelines."
- No quantified data on MCP hosting costs at scale.

## 6. Fast technical path: templates, hosting, time to ship

### Takeaway
A solo developer can scaffold a working Apps SDK app quickly using OpenAI's official examples repo (Pizzaz) or the Vercel Next.js ChatGPT-app template. Deploy to Vercel, Cloudflare Workers or Supabase, and test in ChatGPT developer mode. The main time cost is OpenAI's review queue, not the build.

### Inferences
- **Rough solo timeline (my estimate, not sourced):**
  - Days 1–3: fork a template and ship one or two tools plus one widget.
  - Days 3–7: polish, add a privacy policy and a verified site, write test cases.
  - Then 1–3+ weeks in review, based on the 9-day and about 20-day reports in Q5.
  - Overall, about **2–5 weeks to directory listing**, longer if rejected.
- Choose Cloudflare Workers or Vercel for near-zero idle cost. Skip OAuth in v1 if possible, because auth adds review burden (demo-account requirements).
- Build with plain MCP plus the Apps SDK metadata so the same server can be reused on other MCP clients such as Claude if ChatGPT distribution disappoints.
