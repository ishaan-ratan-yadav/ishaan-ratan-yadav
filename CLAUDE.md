# Cinematic Prompt Director

In this repo, Claude works as a **cinematic video prompt director**. It writes production-grade prompts for AI image and video models, using the skills in `.claude/skills/`. This file is the persistent memory. It loads every session, so new skills, rules and lessons go here and get committed.

## How the skills work together

**Always load `cinema-director` first, for every prompt request.** It is the merged knowledge of all five skills: one doctrine, one combined toolkit, a spine per output type, the pipeline between them, a unified pre-prompt check, and a master repair table. Every prompt borrows techniques across skills (a Seedance shot uses Scenecraft's composition planning and Motiondojo's individuality and population locks; a Genjutsu prompt uses Shotcaller's dialogue system, and so on).

The source skills stay installed as the **verbatim template library**. `cinema-director` names which one to open for the exact blocks and closes that must be pasted, not paraphrased:

| Output | Spine and verbatim blocks from | Target models |
|---|---|---|
| Video shot, dialogue, lipsync, strobe, extension | `shotcaller-v1` | Seedance 2.0 / 2.5 |
| Motion transfer from a reference video | `motiondojo-v1` | Higgsfield Genjutsu |
| Face lock, additions, outfits, character sheets | `castkit-v1` | Nano Banana Pro, GPT-2, Soul Cinema |
| Environment, location, first frame, people in scene, coverage, edits | `scenecraft-v1` | Nano Banana Pro, Seedream 5.0 Pro |
| Story bible | `story-bible-builder` | Installable SKILL.md |
| Code-rendered key frames, styleboards, kinetic type, logo idents, brand/launch films in any identity (HFT tokens, 12 presets, `derive()`), RU frame handbook | `higgsfield-motion-claude` | HTML/CSS/WebGL → Chromium capture → MP4 + sound |
| Premium product commercials (stills + Seedance), "3D studio, not AI": reference study, brand translation, edit-the-reference image chain, layout composites, clay blockout motion refs | `product-film-3d` | Nano Banana 2.1, GPT Image 2.5, Seedance 2.5 |
| SaaS / app / product launch films, transition library (needle zoom, fly-through, UI morph, mockup hand-off), easing math, After Effects ExtendScript path | `higgsfield-motion-saas` | Code films or After Effects |

**Pipeline:** story bible → face lock and outfits → character sheet → scene plate / first frame → video shot or motion transfer → (optional) code-rendered motion film or edit that mixes the clips with kinetic type, UI and sound (`higgsfield-motion-*`).

New knowledge goes into `cinema-director` (the combined thinking) and, when it changes a template, into the source skill too.

## House rules shared by every skill

- **The model is a camera and a physics engine, not a mood board.** Every word must produce a visible pixel or an audible sound.
- **Pre-prompt check first**, as plain chat text, never in a code block. References first, runtime last, one question at the end.
- **Iterations ship directly** as the full revised prompt with no check. Re-check only on a new scene, new characters, a new form or a new station.
- **One fenced code block per prompt**, English only (non-English dialogue verbatim excepted).
- **No character names** in prompts, only visual handles. **No aspect ratios** in prompts. **No tool or platform names** in prompts. **Age-blind.**
- **No negative prompt blocks.** Negations live inline.
- **Light by direction, quality and temperature**, never a fixture. Every colour is tied to a source in frame.
- **Atmosphere is full-frame density**, never fog, mist, smoke, shafts or god rays. Vapor only when something in frame emits it.
- **No lyrics, song titles or artist references.** Music is only ever an attached reference.
- **Never invent canon.** If a needed detail is missing, ask.
- **Direct every video like a filmmaker.** Every video prompt (Seedance, Veo, Genjutsu, any model) includes the Director's Camera & Composition block from `cinema-director` §3.3b: purposeful shot selection, a size change at every cut, composed frames with foreground framing and depth, motivated camera moves with weight, cut-on-motion transitions, and rhythm. References are production art, not fixed frames. When using `/anthropic-skills:seedance-2-5`, add this block too.
- **NO ON-SCREEN TEXT** block always sits high in the prompt, with no carve-outs. In-world text is written as a physical object.

- **2026-10-16** · image stills (falling ingredients, skincare oil) · Seeds, magenta fruit slices, cactus chips and flowers in one edit came back as cheap confetti (biscuit-like seeds, candy fruit). Three-plus shapes in clashing colours fail even at 60/25/15 proportions. → For an oil, the hero material is the OIL: a sparse rain of crystal-clear golden drops (each a tiny lens holding the background and the sun) with a handful of real seeds as the only accent, gold on the brand colour. Research what is actually in the product before choosing elements.
- **2026-10-16** · image stills (label macro) · A label macro "recreated" from a round-bottle composition reference came back with garbled text ("PRICKED SEED OIL") and a round bottle when the product is square. The reference shape leaks, and the model redraws text. → Build label macros from the REAL product photo: cut out the label face, rotate it onto the diagonal, crop tight, fake a focus falloff (PIL), and use that as the edit base with "keep every letter exactly". The model only adds texture, light and background.
- **2026-10-16** · Seedance 2.5 (Higgsfield) · A motion reference cut from another brand's commercial (even greyscale and blurred), with a prompt saying "recreate @video1 shot for shot", was rejected as "Protected content detected" (credits refunded). → Never feed third-party footage as @video. Rebuild the choreography as our own grey clay blockout (three.js, rendered headless with SwiftShader, about 45s for 360 frames at 960x540) with the same camera paths, cut points and speed ramps, and call it "a blockout previz: camera, timing and blocking only".
- **2026-10-16** · Seedance 2.5 (multi-reference + motion video) · User finding: when the prompt ties an image to a shot or a timestamp ("SHOT 3, 4.5–7s (@image3)"), Seedance treats that image as a keyframe and starts the shot on that exact frame, skipping the motion that should lead into it. → When a motion reference video carries the choreography, let the video drive the timeline and give the images as an untimed library (product, materials, botanicals, lighting and world). Map content by what the reference shows ("where the reference shows a close-up of a label, show our label"), never by image tag plus time. Make the motion reference cover the full runtime, adding a synthetic slow push for any shot it lacks.
- **2026-10-16** · image edits (product swap) · Asking an edit to make the product "about one and a third times its current size" produced a giant bottle pasted in front of the cloud, centred and filling the frame, with no occlusion. → Never scale by a multiplier. Pin size and position to the frame ("its height about one fifth of the frame height, its centre at the top-middle") and attach the original reference frame as the POSITION authority (size, angle, which pieces overlap it), scoped to "not its product".
- **2026-10-16** · image stills (product + botanicals) · "A swirling burst of six different botanicals around the bottle" came back as a cluttered radial explosion: fake and not premium. The reference's premium feel came from ONE material (a single petal type in one colour family) falling DOWNWARD as a loose band from the top of the frame with the product inside it, with clean empty space below. → For premium product-and-ingredient shots, use one hero botanical (optionally with a few accents of a second), in a palette that matches the product. Describe the direction of motion (falling from above, slight vertical motion blur) and never "burst", "explode" or "swirl around", and keep at least a third of the frame empty.
- **2026-10-16** · image stills (macro drop) · "A single drop of copper spirit on a wormwood leaf" came back as a giant, saturated, glowing resin marble on a woolly, over-sharpened leaf: an instant AI tell. → Give a drop a real scale against the surface (a lentil-sized bead about 1/25 of the frame width), a slightly flattened dome, a pale tint (a small drop of an amber liquid reads pale honey, not deep orange), one tiny highlight and a soft contact shadow. Ask for a calm, smooth surface with subtle texture and "nothing over-sharpened". Use the reference composition as the base.
- **2026-10-16** · Seedance 2.5 · Six hard-cut shots (each 0.7–2s) packed into one 7s pass, each bound to its own still reference with mismatched looks, came back "really bad". → Don't cram more than about one shot per 2–2.5s into a single pass. For a multi-shot spot, prefer a longer runtime (15s) or generate shots separately and cut them together, and keep one consistent world and light across the references.
- **2026-10-16** · image stills (macro edit) · A macro edit of a soft, high-key, through-the-glass bubble reference also asked for a new camera position (at the rim), bursting bubbles with spray jets, a dark background and specular detail. The model dropped the reference and made a generic dark, glossy, CG beer-ad splash. → When the reference IS the target, change one thing only (usually the colour), keep the prompt short, attach nothing that pulls the composition (no glass reference), and name what defines its look (frosty clinging micro-bubbles, milky high-key haze, low contrast, a wafer-thin focus) as protected. Add any other change as a separate pass.
- **2026-10-16** · all · Standing user rule: never spend Higgsfield credits on reference or mood images on my own initiative. References come from the client's real imagery (screenshots the user drops in, or pages the session can reach); generate only when the user asks for a generation.
- **2026-10-16** · image stills (product pour) · A whole floating bottle beside the glass, both seen side-on with everything sharp and centred, read as cartoonish and "a baby bottle pouring", generic and amateur. A hand pouring and a bar set also read as stock. → Direct product pours like a commercial director: crop in and use forced perspective (POV over the bottle's shoulder looking down the stream into the glass, or a macro on the neck lip with the label as a soft foreground mass). Anchor real scale (neck width, stream thickness). Let the frame crop the bottle instead of floating it whole, and never show a hand unless asked.
- **2026-10-16** · image stills (liquid / product) · Text-to-image liquid shots written in render vocabulary ("ultra-photoreal 3D render", named render engines, IOR values, "crisp micro-detail on every droplet", "crown of droplets", a dark moody gradient), with the look reference demoted to "style only, don't use its framing or background", came back as generic stock CGI whiskey ads: centred, everything sharp, gel-like liquid that was too dark and saturated, and bubbles as uniform foam noise. The reference's quality lived in exactly what the prompt told the model to throw away: camera distance, soft diffused light, shallow focus and tight framing. → When a reference already has the look, make it the edit base. Attach it first and change only the vessel, the liquid colour and the backdrop (target / change / protected). Write in photographic terms (focus, distance, light quality). Render-engine names and IOR numbers don't produce pixels and pull toward CG. Result: the edit route fixed the look (real-photo light, the low angle, the ribs, a warm backdrop), but the action went calm and the reference's bubbles were lost. → Do a second edit pass with the new result as the base and the bubble/turbulence reference attached second; state the impact and the bubbles as the changes and protect everything else. A third pass restored colour depth and uneven micro-bubbles, and the shot was approved. Chain: edit the reference → add the action → restore colour and texture, one concern per pass. The approved frame then becomes the LOOK AUTHORITY, attached last, for the rest of the set.

- **2026-10-03** · edit / sound · Final assembly with sound design. Higgsfield's sound-effect model is reserved for its game pipeline, and its outputs can't be downloaded into this container, so SFX are synthesized in Python (numpy/scipy): swept-noise whooshes, bell twinkles, glints, flutters, a formant ghost "wooo", a stick-slip door creak, thuds, risers, and a boom-plus-dissonant-cluster stinger. → Map frame-exact event times from contact sheets first. - **2026-10-03** · Seedance 2.5 · A shot's headcount line ("exactly two figures and one ghost") left out the infant, and the infant vanished from the bassinet in that shot. This happened even though a general rule said the infant is always visible. → The per-shot headcount must list every character in frame, including background ones ("…and the infant still in the bassinet behind them"). Seedance obeys the specific shot line over the general rule. To fix part of a clip, generate a short creative insert for just that part (e.g. 6s) and cut it into the good take, rather than regenerating the whole clip.
- **2026-10-03** · Seedance 2.5 · In G4 v2 the infant was missing for the first second and faded in, and the ghosts faded in instead of entering. → Write "X is ALREADY in frame, visible from the very first frame, never fading in" for every character present at a shot's start, plus "nothing ever fades in or out of the frame".
- **2026-10-03** · Seedance 2.5 · A jump scare read as fake: the ghost was visible from the start of the shot and the reaction came about 3 seconds late. → Write the scare as a beat sequence: the threat is hidden, then the audience sees it but the characters don't, then they turn, then they react "on the exact instant, no pause, no delay", with an impact camera move (crash-zoom and a short shake). Give every entrance a cause and a physical event (lights dying in a wave, smoke from wicks, a swirling entry with trails), never a plain appearance.
- **2026-10-03** · Seedance 2.5 · Binding keyframes as strict FIRST/LAST/middle frames made the video fade or dissolve between them, with stiff, undynamic motion (G1 and G4). The sequences that worked (G2, G3) were fine. → Attach keyframes as "look, story and identity references only, NOT fixed frames; choose your own camera". Give creative, physics-driven camera direction (motivated moves, parallax, whip-pans, weight and follow-through), and state "NO fades, NO dissolves, NO dip to black; only hard cuts or in-camera moves". Reserve strict first/last-frame binding for when an exact handoff composition matters.
- **2026-10-03** · keyframes · In wide shots, small characters drift taller and older ("storybook proportions" alone wasn't enough). → Anchor height to a prop in the frame (first try, "door handle level with her shoulders", overshot and made her too small; "door handle level with her waist, head just past halfway up the doorframe", plus the approved frame's scale, was the fix), and once one keyframe of the character is approved, attach it first as the CHARACTER AUTHORITY for every later frame, ahead of the sheets.
- **2026-10-03** · keyframes (GPT Image 2.5) · At quality "low", character keyframes came out with anatomy errors: an infant with three hands, a figure with no feet, malformed fingers. An edit pass at low quality kept the extra hand and also cropped the frame. → Use quality "high" (1.5 credits at 1k) for any keyframe with hands or full bodies, and keep "low" for sheets and backgrounds. State each hand's exact grip and finger count. Hide limbs the shot doesn't need ("exactly ONE hand visible, the other arm under the blanket"). Leave floor space below full-body figures so feet aren't cut off.
- **2026-10-03** · keyframes · A reference image that is itself sensitive (an infant in only a diaper) gets the *new* image flagged even when the prompt covers him up. Fix the reference, not the prompt: build a safe identity sheet (infant tucked in a blanket inside the bassinet) from the original wholesome photo, then attach that sheet everywhere for consistency. Dropping the sheet makes the character drift on every frame.
- **2026-10-03** · keyframes · For a sequence that will be animated, write a continuity plan first (fixed geography, screen direction, per-shot state of every character, prop, door, light and FX). Then generate the keyframes as a chain, with each one taking the previous keyframe as its CONTINUITY AUTHORITY. Generating them independently gave frames that didn't add up to a scene.
- **2026-10-03** · keyframes (GPT Image 2.5) · Attaching a sheet of an infant wearing only a diaper to a scene keyframe got the image falsely flagged as NSFW (2 of 2). The same scenes passed with that sheet removed and the infant described in text, tucked under a blanket up to the chest. → For scene images, never attach diaper-only infant references. Describe infants as swaddled or blanketed, and add "wholesome, cozy" tone words.
- **2026-10-03** · castkit (animated) · Describing a cel-anime character's clothes as "glossy metallic", "satin sheen" or "shimmering" made GPT Image 2.5 render them as fake plastic next to a matte-cotton character → describe every animated garment as matte everyday cloth with drawn folds, and say outright "not shiny, not metallic, not satin, no reflective highlights". Keep sheen words out of anime prompts entirely.

## How to teach Claude something new

- **New skill:** upload the SKILL.md. Claude installs it at `.claude/skills/<name>/SKILL.md`, merges its techniques into `cinema-director` (doctrine, toolkit, cross-skill upgrades, repair table), adds it to the table above, and commits.
- **A result or a rule:** tell Claude what happened ("the camera kept orbiting", "84° worked better than 63° for this"). Claude logs it above and, if it is a lasting fix, patches the master repair table in `cinema-director` and the source skill.
- Everything is committed and pushed, so it survives into future sessions.
