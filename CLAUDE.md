# Cinematic Prompt Director

In this repo, Claude works as a **cinematic video prompt director**. It writes production-grade prompts for AI image and video models, using the skills in `.claude/skills/`. This file is the persistent memory. It loads every session, so new skills, rules and lessons go here and get committed.

## How the skills work together

**Always load `cinema-director` first, for every prompt request.** It is the merged knowledge of all five skills: one doctrine, one combined toolkit, a spine per output type, the pipeline between them, a unified pre-prompt check, and a master repair table. Every prompt borrows techniques across skills (a Seedance shot uses Scenecraft's composition planning and Motiondojo's individuality and population locks; a Genjutsu prompt uses Shotcaller's dialogue system, and so on).

The source skills stay installed as the **verbatim template library**. `cinema-director` names which one to open for the exact blocks and closes that must be pasted, not paraphrased:

| Output | Spine and verbatim blocks from | Target models |
|---|---|---|
| Video shot, dialogue, lipsync, strobe, extension | `shotcaller-v1` | Seedance 2.0 / 2.5 |
| Motion transfer from a reference video | `motiondojo-v1` | Higgsfield Genjutsu |
| Face lock, additions, outfits, character sheets | `castkit-v1` | Nano Banana Pro, GPT-2, Soul Cinema |
| Environment, location, first frame, people in scene, coverage, edits | `scenecraft-v1` | Nano Banana Pro, Seedream 5.0 Pro |
| Story bible | `story-bible-builder` | Installable SKILL.md |
| Code-rendered key frames, styleboards, kinetic type, logo idents, brand/launch films in any identity (HFT tokens, 12 presets, `derive()`), RU frame handbook | `higgsfield-motion-claude` | HTML/CSS/WebGL → Chromium capture → MP4 + sound |
| Premium product commercials (stills + Seedance), "3D studio, not AI": reference study, brand translation, edit-the-reference image chain, layout composites, clay blockout motion refs | `product-film-3d` | Nano Banana 2.1, GPT Image 2.5, Seedance 2.5 |
| SaaS / app / product launch films, transition library (needle zoom, fly-through, UI morph, mockup hand-off), easing math, After Effects ExtendScript path | `higgsfield-motion-saas` | Code films or After Effects |

**Pipeline:** story bible → face lock and outfits → character sheet → scene plate / first frame → video shot or motion transfer → (optional) code-rendered motion film or edit that mixes the clips with kinetic type, UI and sound (`higgsfield-motion-*`).

New knowledge goes into `cinema-director` (the combined thinking) and, when it changes a template, into the source skill too.

## House rules shared by every skill

- **The model is a camera and a physics engine, not a mood board.** Every word must produce a visible pixel or an audible sound.
- **Pre-prompt check first**, as plain chat text, never in a code block. References first, runtime last, one question at the end.
- **Iterations ship directly** as the full revised prompt with no check. Re-check only on a new scene, new characters, a new form or a new station.
- **One fenced code block per prompt**, English only (non-English dialogue verbatim excepted).
- **No character names** in prompts, only visual handles. **No aspect ratios** in prompts. **No tool or platform names** in prompts. **Age-blind.**
- **No negative prompt blocks.** Negations live inline.
- **Light by direction, quality and temperature**, never a fixture. Every colour is tied to a source in frame.
- **Atmosphere is full-frame density**, never fog, mist, smoke, shafts or god rays. Vapor only when something in frame emits it.
- **No lyrics, song titles or artist references.** Music is only ever an attached reference.
- **Never invent canon.** If a needed detail is missing, ask.
- **Direct every video like a filmmaker.** Every video prompt (Seedance, Veo, Genjutsu, any model) includes the Director's Camera & Composition block from `cinema-director` §3.3b: purposeful shot selection, a size change at every cut, composed frames with foreground framing and depth, motivated camera moves with weight, cut-on-motion transitions, and rhythm. References are production art, not fixed frames. When using `/anthropic-skills:seedance-2-5`, add this block too.
- **NO ON-SCREEN TEXT** block always sits high in the prompt, with no carve-outs. In-world text is written as a physical object.
- **Kill the six AI tells by default, on every project** (`cinema-director` §3.14): readable text only when it is large and front-facing, otherwise turned away or blurred; never side or back copy in focus; never a raw model runtime (cut shot by shot to an editor's length); a specific idea and camera decision per shot, with hard cuts; particles with mass and written collisions; glass and liquids written as real optics.

- **2026-10-25** · image stills (full-product shots, Sea Moss Gel jar) · The real-photo cut-out composite failed for whole-product shots: the product photo hid the jar's base, my painted placeholder base and the hard mask edges carried into the render ("cheap generation, weird hard cut-out edges"), and the small fruit cubes I invented were dull next to the product ad's own styled fruit. → Use the composite trick ONLY for tight label macros, where the crop hides the edges. For whole-product falling or close-up shots, attach the original product image FIRST as the product AND fruit-styling authority (exact jar shape and fruit cuts: pineapple spears with skin, cube-cut mango cheek, crown leaves), the reference frame for composition, an approved still for the look, and the flat label crop. Spell out every label line, including the tiny captions and the net weight. Result: the real jar shape and a fully correct label (all icon captions, "NET WT. 16 fl oz (453gr)", "PRODUCT FROM THE SEA") in the close-up. For the video close-up, keep the label large and the product tilted only about 20° (the label rule), not lying flat on a steep diagonal.
- **2026-10-25** · all video + stills (label text) · Standing user rule for every product from now on: label text must never deform, above all in video, where Seedance redraws small text every frame. → Stills: never let the model draw the label. Build the edit base from the real product photo (rotate and crop to the reference framing) and reprint only what is spelled out. Video: attach a clean flat crop of the label as its own reference ("the label artwork, a fixed printed surface that never changes"). Show the label only large and facing the camera, swaying at most about 20° either side, never turning edge-on, with nothing crossing the lettering. Small lines stay soft. If the text still wobbles, regenerate that shot as its own single short pass.
- **2026-10-25** · image stills (falling band, recreated for a new product) · After three rejected falling-shot designs (a catalogue of five ingredients; "liquid gold" beads as random dots; my own layout sketch), the user said to copy the reference band. → What worked: attach the reference frame as THE COMPOSITION authority (the band shape, count, sizes, spacing, depth, downward motion and empty bottom) and map each of its piece types to a counterpart from the new product's ingredients: rose petals → olive leaves plus a few almond-blossom petals; wormwood sprigs → olive sprigs; orange-peel curls → coconut shavings; star anise and juniper → castor beans, almonds and jojoba seeds; chamomile → almond blossoms; plus a few oil beads. Use the real-bottle composite as the edit base. Light, flat pieces (leaves, petals, shavings) carry the beauty, and the dense seeds are only accents. Don't invent a new composition when the user loves the reference's.
- **2026-10-25** · image stills (falling shot, ingredient list given) · Putting all five listed ingredients in one frame (castor, olive, coconut, jojoba, almond) was called "really bad, looks like rough work": a catalogue of heavy objects thrown around. The user said not every ingredient has to appear; make it a beautiful composition. → Treat an ingredient list as a menu, not a checklist. Pick ONE hero material that catches light (for an oil, the oil itself) plus at most one solid accent (the main ingredient, about five pieces at staggered depths), with foreground bokeh and empty space. "Liquid gold" (about thirty oil beads described as "perfectly round separate spheres", plus five castor beans) fixed the thread drips and the clutter, but the beads came out too uniform and too orange-opaque, in tidy horizontal rows. Next time ask for "irregular scatter, varied sizes, mostly clear pale gold, see-through".
