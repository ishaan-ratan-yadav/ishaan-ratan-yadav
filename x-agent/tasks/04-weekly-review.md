# Task 04: Weekly review (Sunday ~10:00 IST)

This is the part that makes the agent better every week. Be rigorous; small samples lie.

## 1. Collect
- Final metrics for all posts of the last 7 days (refresh anything younger than 72 h).
- Follower count each day (from `type=daily` rows). Net new followers this week = north star.
- Reply log: which replies brought profile visits/follows (spikes in followers on the day/hour after).
- Watchlist: each core creator's week (posts, best post, follower change), plus newcomers found this week.

## 2. Analyse
- Rank posts by: views, engagement rate ((replies+reposts+quotes+likes+bookmarks)/views), and est. follows.
- Break down by pillar, format, hook type, slot/time, media vs text, trend-bridge vs evergreen, thread vs single,
  70/20/10 bucket. Report sample sizes. A pattern needs ≥3 posts before it's "proven".
- Compare our results with arena outliers this week: what did winners do that we didn't?
- Check each experiment in `memory/experiments.md`: confirmed / rejected / needs more data.
- Check health: any sudden drop in views across all posts (possible throttling)? Any negative replies, mutes, blocks?

## 3. Decide
- **Double down:** patterns that won → move into the 70% bucket in the playbook.
- **Iterate:** near-misses → variations next week (20%).
- **Kill:** patterns that lost twice.
- **New bets:** 2–3 wild ideas from the swipe file (10%).
- **Post count & slots:** update `memory/schedule.md`. Raise posts/day only if the per-post median held up while
  posting more; lower it if extra posts diluted reach (author-diversity decay). Safe range 2–5 main posts/day.
- **Watchlist:** promote/demote creators; keep ≥15 core, ≥40 total, always including fast risers.
- **Premium check:** if reach is the bottleneck (good engagement rate but low views) for 2+ weeks, recommend Premium with numbers.

## 4. Write
- `memory/playbook.md`: bump version, add/remove rules with evidence (post links + numbers). Keep a changelog.
- `memory/experiments.md`: next week's hypotheses.
- `memory/weekly/YYYY-WW.md` report: headline numbers vs last week, top 3 posts and why, flops and why,
  what changes next week, render requests for the week (hero spec ad / FOOH idea tied to a predicted trend or event),
  profile tweaks, and decisions needed from Ishaan.
- Telegram: 8-line summary + path to report. Open the report in Chrome.

## 5. Monthly (first Sunday of the month)
Also review positioning and pillar mix, profile (bio/banner/pinned) A/B result, and whether the arena definition
should widen or narrow.
